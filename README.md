# Enterprise AI RAG Platform

An enterprise AI knowledge platform that allows users to upload
documents and interact with them using Retrieval-Augmented Generation (RAG).

## 🚀 Features

- Document upload and processing
- PDF and DOCX support
- Text chunking
- Vector embeddings
- Semantic search
- Retrieval-Augmented Generation
- LLM-powered answers
- Source citations
- Conversation history
- Authentication and authorization
- AI evaluation
- Docker deployment
- CI/CD with GitHub Actions
